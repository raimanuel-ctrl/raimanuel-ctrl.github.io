## 🌐 Cómo Publicarla GRATIS en Internet con GitHub Pages (En 3 Minutos)

Para que tu página tenga una dirección web propia (por ejemplo: `https://raimanuel-ctrl.github.io/` o `https://raimanuel-ctrl.github.io/portfolio`) y puedas colocarla en tu LinkedIn:

### Opción A: Como tu sitio principal (`https://raimanuel-ctrl.github.io`)
1. Entra a tu cuenta de GitHub ([github.com](https://github.com)).
2. Crea un nuevo repositorio público con el nombre exacto:  
   `raimanuel-ctrl.github.io`
3. Sube los archivos de esta carpeta (`index.html`, las carpetas `css/`, `js/`, `assets/`).  
   Puedes hacerlo arrastrando los archivos a la web de GitHub o por terminal con git:
   ```bash
   git init
   git branch -M main
   git remote add origin https://github.com/raimanuel-ctrl/raimanuel-ctrl.github.io.git
   git add .
   git commit -m "Publicar mi portafolio y curriculum web"
   git push -u origin main
   ```
4. ¡Listo! En 1 minuto tu página estará activa en `https://raimanuel-ctrl.github.io`.

### Opción B: Como repositorio `portfolio`
1. Crea un repositorio llamado `portfolio`.
2. Sube estos archivos.
3. Ve a **Settings > Pages > Branch: main > Save**.
4. Tu web estará en: `https://raimanuel-ctrl.github.io/portfolio/`.
