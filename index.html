Módulo 02 · Transformada Chi & ksn

Perfiles_chi_ksn.ipynb

Extracción del cauce principal, integración de la coordenada espacial transformada Chi (χ) linealizando perfiles de equilibrio (con concavidad teórica θ = 0.45 y A0 = 10⁶ m²) y cálculo del índice de pendiente normalizada (ksn local).

NumPy SciPy θ = 0.45 A0 = 1,000,000 m² Ventana = 500 m
Ver Notebook en GitHub
notebooks/Perfiles_chi_ksn.ipynb 
import numpy as np

# Parámetros morfométricos estándar de referencia
A0 = 1.0e6          # Área de referencia (m²)
theta_ref = 0.45    # Concavidad teórica de referencia (Perron & Royden)

def calcular_coordenada_chi(dist_upstream, drainage_area, theta=0.45, A_0=1e6):
    """
    Calcula la transformada Chi (χ) a lo largo del perfil:
    χ = ∫ (A_0 / A(x'))^θ dx'
    """
    dx = np.gradient(dist_upstream)
    integrando = (A_0 / drainage_area) ** theta
    return np.cumsum(integrando * dx)

# Índice de pendiente normalizada de canal: S = ksn * A^(-theta)
def calcular_ksn_local(elevation, dist_upstream, drainage_area, theta=0.45):
    # Pendiente local suavizada con ventana móvil de 500 m
    slope_local = np.abs(np.gradient(elevation, dist_upstream))
    return slope_local * (drainage_area ** theta)
Módulo 03 · Detección de Knickpoints

AnalisisPerfiles.ipynb

Ajuste de regresiones lineales por tramos en el espacio χ–Elevación para identificar perturbaciones tectónicas o caídas de nivel de base. Detección automatizada de candidatos a knickpoints mediante curvatura y comparación con TopoToolbox.

Knickpoints Piecewise Regression TopoToolbox Curvatura d²z/dχ²
Ver Notebook en GitHub
notebooks/AnalisisPerfiles.ipynb 
from scipy.signal import find_peaks
import numpy as np

# En equilibrio geomórfico: z(x) = z_base + (ksn / A0^theta) * chi
# Rupturas de pendiente en espacio chi indican pulsos tectónicos

def identificar_knickpoints(chi, elevation, prominence=0.015, min_dist=25):
    # Segunda derivada numérica de la elevación con respecto a Chi
    d_elev = np.gradient(elevation, chi)
    curvatura_chi = np.gradient(d_elev, chi)
    
    # Detección de anomalías morfológicas
    peaks, _ = find_peaks(
        curvatura_chi, 
        prominence=prominence, 
        distance=min_dist
    )
    return peaks

# Migración remontante de knickpoints (knickpoint retreat)
# Velocidad de onda de incisión: v_k = dx/dt = K * A^m * S^(n-1)

def tiempo_propagacion_delta_t(chi_knickpoint, K_erodabilidad, A0=1e6, m=0.45):
    """
    Tiempo de respuesta del canal fluvial ante caída de nivel de base:
    Δt = χ_kp / (K * A_0^m)
    """
    return chi_knickpoint / (K_erodabilidad * (A0 ** m))
